# 개인용 여행 플래너 — Claude Code 인수 패키지

Claude Code가 이 폴더만 보고 앱을 처음부터 끝까지 만들 수 있도록 정리한 설계·인수 패키지입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `PROMPT.md` | **Claude Code에 보낼 첫 프롬프트** |
| `CLAUDE.md` | 매 세션 시작 때 읽는 작업 규칙 요약 |
| `docs/SPEC.md` | 전체 기능 명세 (화면 15종, 서버 함수, 구현 단계 M0~M19, 디자인, 트리플 접목 부록) |
| `docs/SETUP_CHECKLIST.md` | 내가 직접 해야 하는 준비 (계정, 키, 결제, 배포) |
| `docs/DECISIONS.md` | 설계 결정과 구현 중 변경 기록 |
| `supabase/migrations/` | 완성된 DB 스키마·권한·함수·스토리지 (0001~0003) |
| `supabase/tests/` | 권한 스모크 테스트와 기대 결과 |
| `starter/` | 검증된 로직 코드와 테스트 (정산, 거리·시간, AI 스키마 등) |
| `.env.example`, `.gitignore` | 환경변수 목록, 무시 파일 |

## 사용 방법

1. 새 폴더에 압축을 풀고 `git init`을 합니다.
2. 이 폴더에서 Claude Code를 실행합니다.
3. `PROMPT.md`의 프롬프트를 복사해 첫 메시지로 보냅니다.
4. Claude Code가 문서를 읽고 계획을 보고하면 "진행"이라고 답합니다.
5. 단계마다 보고를 확인하고, 안내하는 준비 작업(`docs/SETUP_CHECKLIST.md`)을 진행합니다.

## 검증된 것과 아닌 것

- **검증됨:** SQL 3개를 Postgres 16에 적용해 권한·함수 동작 16개 구역을 확인했습니다(RLS, 컬럼 권한, 지출 저장 검증, 읽기 전용 공유, 복제, 스토리지 정책, 연쇄 삭제). 로직 코드는 TypeScript strict 타입체크와 테스트 28개를 통과했습니다.
- **미검증:** 실제 Supabase 환경에서의 실행, 외부 API(Google, Gemini, OpenRouter) 연동, 화면 구현은 아직 없습니다. 외부 API 형식과 모델명은 구현 시점에 공식 문서로 확인하도록 지시되어 있습니다.
- 트리플 앱 정보는 사전 지식 기준이라 현재 앱과 다를 수 있습니다(`docs/SPEC.md` 부록 F-0).
