# 지리 데이터 출처와 라이선스

| 파일 | 출처 | 라이선스 |
|---|---|---|
| `countries-110m.json` | [world-atlas](https://github.com/topojson/world-atlas) 2.0.2 (Natural Earth 기반, Michael Bostock) | ISC (npm 패키지 LICENSE 확인). Natural Earth 데이터는 퍼블릭 도메인 |
| `kr-municipalities.json` | [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps) `kostat/2013/json/skorea_municipalities_topo_simple.json` (통계청 KOSTAT 센서스용 행정구역경계 2013) | 저장소 README: "KOSTAT: Free to share or remix." (2026-10-12 확인). GADM·POPONG 데이터는 사용하지 않음 |

- 개인용 앱 기준으로 확인한 내용이다. 상업적 배포를 하게 되면 KOSTAT 원본 이용 조건을 다시 확인할 것.
- 행정구역 경계는 2013년 기준이라 이후 변경(예: 통합·분구)은 반영되지 않는다.
